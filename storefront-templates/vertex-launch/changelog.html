New v4.2 · 2026-03-04

Linear and Jira sync

  • •Issues linked from a pull request now carry their title and status into the draft, so an entry can say what a fix actually unblocked rather than repeating the branch name.
  • •Two-way: publishing an entry posts a comment back on the issue with a link to the live changelog.
Breaking

The issue_refs field on the API changed shape from an array of strings to an array of objects. The old shape is served until 1 June if you send Accept-Version: 3.

Improved v4.1 · 2026-02-19

Grouping got a lot better

  • •Related pull requests now collapse by shared issue reference as well as by file overlap, which cut the average entry count on our own repo from eleven to four.
  • •Dependency bumps are hidden by default. There is a toggle in settings if your customers care about them, and some genuinely do.
New v4.0 · 2026-01-28

Custom CSS on hosted pages

  • •Paid plans can now upload a stylesheet for their hosted changelog. It is scoped to the content area and cannot break the layout, which was the whole reason this took so long.
Fixed v3.9 · 2026-01-09

Fixes

  • •Entries with more than forty linked pull requests no longer time out on save.
  • •The Slack webhook stopped truncating entries at 300 characters mid-word.
  • •Fixed a case where re-opening a merged pull request created a duplicate draft.
